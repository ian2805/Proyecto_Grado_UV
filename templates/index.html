Desarrollo de un aplicativo web para la predicción binaria del índice UV en Barranquilla

Aplicativo web orientado al análisis histórico del índice de radiación ultravioleta y de variables ambientales asociadas, así como a la clasificación predictiva de condiciones UV mediante técnicas de aprendizaje automático.
